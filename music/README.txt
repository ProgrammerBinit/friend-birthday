Put your legally-owned MP3 file here and rename it to: song.mp3

Example:
  public/music/song.mp3

The site is already wired to auto-play "Meri Yaar Meri Daulat" (or whatever
song you place here) as soon as the site loads — if the browser blocks
autoplay-with-sound (Chrome/Safari do this by default until the user
interacts with the page), a small "Tap to play sound" bubble appears next
to the floating music player, and playback starts on the very next click,
scroll, or key press anywhere on the page.
